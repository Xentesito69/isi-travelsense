# 🧭 Customer Journey 

1. El usuario accede a TravelSense desde la web. 

2. Introduce ciudad, fechas e intereses (ocio, deporte, gastronomía). 

3. El sistema consulta las APIs externas (clima, mapas y lugares). 

4. TravelSense procesa los datos y genera un plan diario optimizado. 

5. El usuario visualiza el plan, lo guarda o lo ajusta.
