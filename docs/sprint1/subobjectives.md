## Subobjetivos

• Integración de Datos: Conexión con APIs externas (Google Maps y OpenWeather) para 
obtener información geográfica y climática en tiempo real.  
• Motor de IA: Implementación de un modelo de lenguaje (LLM) que cruza los datos de las APIs 
con los gustos del usuario para crear planes personalizados.  
• Gestión de Datos: Diseño de una base de datos para almacenar perfiles de usuario e historiales 
de itinerarios.  
• Interfaz Web: Desarrollo de una plataforma visual (GUI) para introducir parámetros de viaje y 
visualizar mapas y cronogramas.  
• Control de Calidad: Pruebas de integración para garantizar que la IA sea coherente y que el 
sistema funcione correctamente bajo cualquier condición climática.
