## CU (2–3 casos de uso)

CU1 – Generación de itinerario narrativo mediante IA
El usuario introduce destino y preferencias. El sistema integra datos externos y genera
automáticamente un itinerario coherente y contextualizado.
CU2 – Optimización contextual dinámica
Ante condiciones meteorológicas adversas, el sistema adapta automáticamente las actividades
propuestas, priorizando alternativas viables y optimizando distancias.
CU3 – Personalización evolutiva
El sistema almacena el histórico del usuario y ajusta futuras recomendaciones en función de sus
preferencias previas.
