## 🎯 Objetivo general 

Desarrollar un MVP (Producto Mínimo Viable) de TravelSense concebido como un sistema de 
soporte a la decisión (DSS) potenciado por Inteligencia Artificial Generativa. El sistema será 
capaz de orquestar datos en tiempo real de múltiples APIs (clima y geolocalización) para generar y 
planificar itinerarios de viaje hiper-personalizados, accesibles a través de una interfaz web intuitiva y 
con persistencia de datos para el seguimiento del usuario
