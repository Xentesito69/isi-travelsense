# 🧩 Business Model Canvas (resumen) 

### Propuesta de valor
  - Planificación inteligente en un solo sitio (clima + mapa + lugares) con recomendaciones contextualizadas. 

### Segmentos de clientes
  - Viajeros urbanos, deportistas ocasionales, amantes de la gastronomía. 

### Canales
  - Web app (MVP), ampliable a móvil. 

### Relación con clientes
  - Autoservicio + personalización (perfil y preferencias). 

### Fuentes de ingresos (futuro) 
  Freemium: básico gratis + premium (más filtros, más ciudades, exportación de planes). 
  - Afiliación/colaboraciones con experiencias (si se quisiera escalar). 

### Recursos clave
  - APIs externas, base de datos, motor de recomendación (scoring), frontend con mapa. 

### Actividades clave
  - Integración de sistemas, procesamiento y ranking, generación de itinerarios, automatización (CI/tests/deploy). 

### Socios clave
  - Proveedores de datos (clima / mapas / lugares). 

### Estructura de costes
  - Infraestructura, consumo de APIs, mantenimiento.
